# How I Work

## Development Style

I prefer building large systems incrementally.

The preferred workflow is:

1. Understand
2. Plan
3. Review
4. Approve
5. Implement
6. Test
7. Verify
8. Continue

## Debugging

I prefer actual diagnosis over guessing.

When something fails:

- identify the actual failure
- determine the root cause
- fix the cause
- test the fix
- check for regressions

## Engineering Preference

Use mature existing infrastructure when it already solves the
problem well.

Avoid rebuilding difficult infrastructure unnecessarily.

## Project Management

Keep the current task focused.

Do not allow future features to derail the current implementation
stage.

Ideas for later should be recorded separately rather than immediately
implemented.
