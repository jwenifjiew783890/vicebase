# User Profile

## About

The user is the creator of the Vision project and is building it as a
long-term personal AI platform.

## Current Major Project

Vision — a local-first, modular AI platform intended to become the
user's primary AI workspace.

## How the User Thinks About Vision

Vision is the product/platform.

Models, runtimes, agents, tools, memory systems, and integrations are
replaceable components underneath it.

## Core Engineering Philosophy

- Prefer mature infrastructure over rebuilding existing systems.
- Keep Vision Core stable and modular.
- Use plugins for optional integrations.
- Keep external systems outside Vision Core when practical.
- Make model/runtime choices interchangeable.
- Treat hardware limitations as runtime considerations, not permanent
  architectural limitations.
- Build incrementally and verify every stage.

## Development Principle

PLAN → APPROVE → IMPLEMENT → TEST → STOP

Vision should remain runnable after every implementation stage.

## Long-Term Goal

Build Vision into a polished AI environment that can eventually
replace the need for separate AI applications for:

- General chat
- Coding
- Local models
- Agents
- Tools
- Projects
- Research
- External integrations
