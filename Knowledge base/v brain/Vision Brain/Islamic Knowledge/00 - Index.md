# Islamic Knowledge

A source-traceable study library. **Separate from `Memory/`** — nothing here is personal
memory, and nothing here decays.

> [!danger] Read this first
> **Nothing in this library is invented.** Every verse, narration and grading was imported
> verbatim from a licence-verified source. Where something is unknown it says `UNKNOWN` or
> `NEEDS VERIFICATION`. Large parts of this library are deliberately **empty** — see
> *What is not here* below, and [[Islamic Knowledge/99 - Source & Authenticity Rules|the rules]].

Organised per your request around the **Ahl al-Hadith / Salaf al-Salih / Salafi manhaj**.
That governs how material is arranged; it never changes what a source is called.

## Two warnings that matter

> [!warning] Presence here does not mean authenticity
> These collections were compiled to different criteria. Roughly **10,000** gradings in this
> corpus read *Da'if* (weak). Always check the grading and the grader before relying on a
> narration.

> [!warning] Bukhari and Muslim carry no grading field here
> That is a property of the dataset, not an implied ruling, and it must not be "fixed" by
> adding gradings. See
> [[Islamic Knowledge/02 - Hadith/04 - Hadith Grading/Grading Methodology|Grading Methodology]].

## Using it

Search guidance: [[Islamic Knowledge/02 - Hadith/05 - Hadith Search Index/How to Search|How to Search]].

Vision reaches this vault through the Obsidian MCP integration and can read these notes
directly. When answering from this corpus it must cite the exact note, name the grader, and
show disagreement rather than resolving it. If the library lacks something, the correct answer
is that it lacks it.

> [!note] This library does not issue rulings
> It is a study and reference aid that points to what scholars actually said, with sources
> attached. Questions of practice go to qualified scholars.
