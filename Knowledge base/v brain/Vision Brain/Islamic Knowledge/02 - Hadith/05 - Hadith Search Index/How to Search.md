# How to Search This Corpus

Every narration lives inside a **book note** rather than its own file - 36,472 separate
notes would make the vault and graph unusable. Search finds them all the same.

## In Obsidian

| Goal | Query |
| --- | --- |
| A phrase anywhere in hadith | `path:"02 - Hadith" "intentions"` |
| Within one collection | `path:"01 - Sahih al-Bukhari" "ablution"` |
| Al-Albani gradings only | `path:"02 - Hadith" "**Al-Albani** — Sahih"` |
| Weak narrations | `path:"02 - Hadith" "Daif"` |
| A specific hadith number | `"Sahih al-Bukhari 1 ·"` |
| Qur'an by verse | `path:"01 - Quran" "2:255"` |

## Asking Vision

Vision reaches this vault through the Obsidian MCP integration, so it can search and read
these notes directly. When it answers from this corpus it must cite the exact source note,
give the grading **with the grader named**, and surface disagreement rather than resolving it.

If the library does not contain something, the correct answer is that it does not.
