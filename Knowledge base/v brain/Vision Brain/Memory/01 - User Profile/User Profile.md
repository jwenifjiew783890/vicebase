## What Vision is (current truth)

> **Open WebUI *is* Vision.** Not "Vision plus Open WebUI".

Vision is the Open WebUI v0.11.3 codebase customised in place. There is no
second frontend, no second backend and no Vision orchestration layer.
`[user 2026-09-03]` `[verified 2026-09-03]`

The earlier standalone Electron / React / TypeScript Vision application is
**abandoned and must not be revived**. `[user 2026-09-03]`

## Working style

- Cares strongly about clean architecture and avoiding unnecessary
  reinvention. `[user 2026-09-03]` `[vault]`
- Prefers mature specialist software to do specialist jobs, rather than
  rebuilding everything into one giant application. `[user 2026-09-03]` `[vault]`
- Expects AI agents and engineering assistants to **perform the implementation**,
  not hand back instructions for the user to execute manually.
  `[user 2026-09-03]`
- Wants Vision to become a unified AI environment while specialised external
  systems stay external. `[user 2026-09-03]`
