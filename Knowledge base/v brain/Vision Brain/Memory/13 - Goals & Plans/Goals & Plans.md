# 13 — Goals & Plans

## The long-term goal

A **unified AI environment** where the user interacts with many specialised AI
and software systems from a single interface. `[user 2026-09-03]` `[vault]`

Vision is the interface. It does not absorb the specialists.

```
Vision
 ├── Models
 ├── Agents
 ├── Tools
 ├── Memory
 ├── Automation
 └── External systems
       ├── Obsidian          ← connected 2026-09-03
       ├── n8n               ← connected
       ├── OpenCode
       ├── OmniVoice
       ├── desktop control
       ├── browser control
       ├── image generation
       ├── Figma
       ├── Blender
       └── future systems
```

## Stated ambition `[vault]`

Vision should become good enough to be the user's **primary alternative to
Claude for everyday AI work** — covering chat, coding, local models, agents,
tools, projects, research and integrations, replacing the need for separate AI
applications. ([Things Vision Should Remember](Memories/Things%20Vision%20Should%20Remember.md.md),
[Important Long-Term Memories](Memories/Important%20Long-Term%20Memories.md.md))

  `[user 2026-09-03]`
