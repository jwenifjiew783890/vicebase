# Memory Archive

Memories that have decayed below the retention threshold, or that were
explicitly forgotten. **Nothing here was deleted** — archived memories stay
searchable when you ask about them directly, and are restored to their original
category folder if they get reinforced again.

`_maintenance.md` records when the last automatic archival sweep ran.

See [[Memory/99 - Memory Rules|99 — Memory Rules]].
