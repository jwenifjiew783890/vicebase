# Product Preferences

## Overall Product Standard

Products should feel:

- Premium
- Polished
- Modern
- Fast
- Professional
- Futuristic without being gimmicky
- Consistent
- Intuitive

The interface should feel like a real finished product rather than
a prototype.

## Vision

Vision should feel like a complete AI platform.

It should not feel like:

- an Ollama wrapper
- an admin dashboard
- a developer dashboard
- a collection of unrelated tools
- a VS Code clone

The user should feel like they are using one coherent AI product.

## Chat Experience

The Chat experience should feel similar in quality and simplicity to
modern premium AI assistants such as Claude.

It should prioritize:

- clean conversation layout
- excellent typography
- spacious composition
- polished composer
- useful actions
- model selection
- attachments
- images
- smooth streaming
- subtle motion

## Code Experience

The Code experience should feel like a Claude Code-style AI coding
workspace.

It should prioritize:

- AI-first interaction
- project context
- real project files
- terminal access
- task progress
- changes/diffs
- permissions
- agent activity

It should NOT become a full traditional IDE.

## Navigation

Primary navigation should remain understandable.

Major experiences should be separated clearly without creating a
large collection of unnecessary pages.

Agents and individual plugins should not clutter the primary
navigation.

## Visual Identity

Vision's visual identity should be distinct.

The Vision Orb should be a recognizable part of the brand.

Visual effects should be purposeful rather than excessive.

## Motion

Animations should be:

- smooth
- subtle
- responsive
- meaningful

Avoid excessive bouncing, flashing or unnecessary motion.

## Accessibility

Controls should have:

- clear labels
- visible focus states
- appropriate contrast
- keyboard support
- predictable behavior

## Performance

Visual quality should not come at the expense of responsiveness.

Heavy visual effects should have performance-conscious fallbacks.

## Extensibility

New capabilities should feel native to Vision without forcing large
changes to the primary UX.

Plugins and integrations should extend the product rather than
redefine it.
