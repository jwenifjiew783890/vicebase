# User Preferences

## Product Style

- Premium
- Modern
- Minimal
- Futuristic
- Professional
- Desktop-first
- Strong visual identity

## Vision UX

Vision should feel like one coherent AI product rather than a
collection of disconnected tools.

Chat should feel like a premium conversational AI application.

Code should feel like a Claude Code-style AI coding workspace,
not a traditional IDE.

## Engineering Preferences

- Use mature tools where they already solve difficult problems.
- Avoid unnecessary reinvention.
- Prefer clean abstractions and replaceable components.
- Keep optional capabilities outside the core when practical.
- Verify functionality rather than assuming it works.
- Be honest about limitations and tradeoffs.

## Architecture Preference

Core systems should be stable.

Optional integrations should be removable without breaking Vision.

Examples include:

- Obsidian
- Blender
- memory systems
- future external services
- future plugins
